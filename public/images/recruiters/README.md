# Recruiter Logo Images

Place recruiter logo files in this folder.

Supported extensions:
- `.webp`
- `.png`
- `.svg`
- `.jpg`
- `.jpeg`

Filename format:
- lowercase
- replace spaces/special characters with `-`

Examples:
- `google.png`
- `microsoft.svg`
- `goldman-sachs.webp`
- `l-and-t-infotech.png` (or alias `ltinfotech.png`)
- `samsung-r-and-d.png` (or alias `samsung-rd.png`)

The recruiters page automatically tries these filenames and falls back to the built-in logo renderer when an image is not found.
